# Logomarks

2,600 free geometric logomarks, CC0, at [logomarks.ai](https://logomarks.ai). Use any of them for anything, no credit needed.

These are the libraries the set is drawn, checked and shown with.

| Package | What it does | npm |
|---|---|---|
| [`@logomarks/core`](https://github.com/Logomarks/core) | Geometry, SVG reading, the 448 fit, analysis and similarity on a 512 grid | [npm](https://www.npmjs.com/package/@logomarks/core) |
| [`@logomarks/editor`](https://github.com/Logomarks/editor) | An in-browser vector editor for marks: parts, points, booleans, live checks | [npm](https://www.npmjs.com/package/@logomarks/editor) |
| [`@logomarks/brand-kit`](https://github.com/Logomarks/brand-kit) | A brand kit and social pack from a mark, a name, a colour and a typeface | [npm](https://www.npmjs.com/package/@logomarks/brand-kit) |
| [`@logomarks/image-effects`](https://github.com/Logomarks/image-effects) | Image filters as data: grading, grain, blurs, halftone, glitches | [npm](https://www.npmjs.com/package/@logomarks/image-effects) |
| [`@logomarks/mockups`](https://github.com/Logomarks/mockups) | Product mockups from finished artwork, as SVG, PNG or three.js scenes | [npm](https://www.npmjs.com/package/@logomarks/mockups) |
| [`@logomarks/mockups-plates`](https://github.com/Logomarks/mockups-plates) | Photo plates for the mockups: real scenes with blank signs | [npm](https://www.npmjs.com/package/@logomarks/mockups-plates) |
| [`@logomarks/shaders`](https://github.com/Logomarks/shaders) | Standalone WebGL scenes: liquid marble, glass, chrome and more | [npm](https://www.npmjs.com/package/@logomarks/shaders) |

**Skills and plugin:** [Logomarks/skills](https://github.com/Logomarks/skills), agent skills to pick a mark or design a new one (Claude Code, Cursor, Codex).
